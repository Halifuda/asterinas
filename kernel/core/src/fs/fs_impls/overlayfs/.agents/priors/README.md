# Priors

This bundle keeps only generic Asterinas-wide priors and placeholder documents.
Filesystem-specific priors must be staged by the adopting workspace.

Suggested minimum set:
- `FILESYSTEM_SPEC_SUMMARY.md`: authoritative spec summary or extracted rules
- `FILESYSTEM_SPEC_INDEX.md`: quick lookup index into the authoritative spec
- `REFERENCE_IMPLEMENTATION_SUMMARY.md`: one or more reference implementation notes
- `MICRO_FEATURE_INVENTORY.md`: feature decomposition used by the Architect and Designer
- `ASTERINAS_INTEGRATION_PRIORS.md`: Asterinas-local integration context
- `ASTERINAS_CODE_QUALITY_PRIORS.md`: reusable code-quality guidance
